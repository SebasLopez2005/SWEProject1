# Round 2 interface requirement

The student requested a dark visual update to the current app. This requirement applies to the shared interface across the workout, history, progress, exercise, template, settings, and onboarding routes.

- **UI-01.** Use a graphite canvas, charcoal content surfaces, warm champagne accents, and light text. Carry the palette into the app icon, tabs, charts, status bar, keyboard, and iOS date picker.
- **UI-02.** Use interactive native Liquid Glass for enabled action buttons on supported iOS builds. Use solid controls when the material is unavailable or Reduce Transparency is enabled. Selected filters, disabled actions, and destructive actions retain distinct states and accessible labels.
- **UI-03.** Keep the existing routes and action labels, minimum touch targets, text scaling, and chart value list. Apply glass to action buttons and keep dense content cards opaque.

The implementation is a UX revision of the Round 1 ChatGPT app from merge commit `492476f9d584dcbc64a35432c7fe2a6fc2b094f7`. The 31 fitness story criteria continue to apply. The [run log](../experiments/RUN_LOG.md) records the brief and verification.
